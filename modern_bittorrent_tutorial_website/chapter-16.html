16. Common errors and troubleshooting

Print metainfo facts without dumping binary pieces

SymptomLikely cause and next action
SyntaxError: Cannot use import statement outside a modulepackage.json is missing "type": "module", or you are running a file outside the project folder. Add the property exactly and run from the folder containing package.json.
ERR_MODULE_NOT_FOUND for a local fileES module relative imports need the .js extension. Use ./src/download.js, not ./src/download.
Cannot find package bencodeRun npm install in the folder containing package.json. Check that node_modules exists and npm did not report an error.
No UDP tracker was foundThe torrent has only HTTP/HTTPS trackers, relies on DHT, or is malformed. Use another legal v1 torrent or implement HTTP tracker support.
UDP tracker did not replyThe tracker may be offline, blocked by a firewall/network, or dropping packets. Try another tracker listed in the torrent. Do not assume the packet builder is wrong until tests pass and multiple trackers fail.
Tracker response has the wrong transaction IDAn unrelated/late UDP packet arrived. Correct code ignores packets while waiting and validates again when parsing.
Tracker returned no peersThe swarm may be empty, the tracker may not know peers, or the info hash may differ because the torrent is non-canonical or v2-only.
All peer connections closed too earlyListed peers may be stale, firewalled, not serving the piece set, or rejecting the basic client. Try another active legal torrent.
Peer connection timed outThe peer stopped responding for 30 seconds. The outstanding block is made available to another peer.
Peer returned a block we did not requestThe peer sent a different index, offset, or length. The client closes that untrusted connection.
Downloaded file is corruptThis educational build does not yet verify completed piece hashes. Implement the integrity step in Chapter 17; also confirm the torrent is v1 single-file and the info hash was calculated from canonical bytes.
EACCES / permission deniedChoose an output folder your user can write to. Do not run the program as administrator merely to bypass a path problem.
Output already existsOpening with w truncates the previous file. Choose another output path if you need to preserve it.
