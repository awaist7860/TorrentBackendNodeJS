14. Run the client safely

index.js

14.1 Create index.js

index.js

JavaScript
import path from 'node:path';
import process from 'node:process';
 
import { download } from './src/download.js';
import {
  isSingleFileTorrent,
  openTorrent,
  torrentName,
} from './src/torrent-parser.js';
 
const [torrentPath, requestedOutputPath] = process.argv.slice(2);
 
if (!torrentPath) {
  console.error('Usage: node index.js <file.torrent> [output-file]');
  process.exitCode = 1;
} else {
  try {
    const torrent = openTorrent(torrentPath);
 
    if (!isSingleFileTorrent(torrent)) {
      throw new Error(
        'This learning client supports single-file torrents only. ' +
        'Multi-file support is explained in the improvements chapter.',
      );
    }
 
    const safeDefaultName = path.basename(torrentName(torrent));
    const outputPath = requestedOutputPath ?? safeDefaultName;
 
    console.log(`Torrent: ${torrentPath}`);
    console.log(`Saving to: ${outputPath}`);
 
    await download(torrent, outputPath);
  } catch (error) {
    console.error(`Download failed: ${error.message}`);
    process.exitCode = 1;
  }
}

14.2 Command-line arguments

process.argv contains the Node executable, script path, and then user arguments. slice(2) removes the first two. The first argument is the .torrent path. The optional second argument is the desired output path.

14.3 Safe default file name

path.basename removes directory components from the name suggested inside the torrent. This prevents a metainfo name such as ../../something from choosing a path outside the current directory. A user-supplied output path is still honoured because the user explicitly typed it.

14.4 Choose a suitable legal test torrent

  • It must be a BitTorrent v1 single-file torrent.
  • It must contain at least one udp:// tracker in announce or announce-list.
  • Use content you are authorised to download, such as an official open-source operating-system image or your own test data.
  • Start with a small file. Public swarms may have no reachable peers, even when your code is correct.

14.5 Run it

Direct Node command

Terminal
node index.js path/to/example.torrent output.bin

Equivalent npm script form

Terminal
npm start -- path/to/example.torrent output.bin

14.6 Expected output

Illustrative output

Terminal
Torrent: path/to/example.torrent
Saving to: output.bin
Tracker returned 18 peer(s).
Progress: 42%
...
Download complete.

Peer counts and progress timing vary. A tracker response does not guarantee that every listed peer is online, reachable, unchoking, or still participating.

14.7 Check the result

Compare the final file size with the torrent size. For a robust client, also verify every piece against info.pieces while downloading. If an official publisher supplies a whole-file checksum, verify that too, but remember that whole-file checksums are separate from the BitTorrent protocol.
