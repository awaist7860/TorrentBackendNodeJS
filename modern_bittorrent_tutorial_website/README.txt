MODERN BITTORRENT CLIENT TUTORIAL WEBSITE
=========================================

Start here
----------
Double-click index.html to open the tutorial in a modern browser.

A local web server is optional. From this folder, you can run:

    python -m http.server 8080

Then open http://localhost:8080

Files
-----
- index.html: tutorial homepage
- chapter-01.html to chapter-17.html: individual chapters
- appendix-a.html to appendix-d.html: source code, protocol layouts, glossary, and references
- assets/css/styles.css: all visual styling
- assets/js/app.js: navigation, search UI, theme, code copy buttons, progress, and page contents
- assets/js/search-index.js: local full-tutorial search data
- assets/favicon.svg: site icon

The website has no framework, CDN, npm dependency, build process, or internet requirement for its interface.
