7. Build and parse the UDP connect exchange

Total size: 8 + 4 + 4 = 16 bytes.

7.1 Connect request layout

OffsetSizeTypeValue
08 bytesunsigned 64-bitProtocol ID 0x41727101980
84 bytesunsigned 32-bitAction 0 = connect
124 bytesunsigned 32-bitRandom transaction ID

Total size: 8 + 4 + 4 = 16 bytes.

7.2 Build the request

Connect request builder

JavaScript
const UDP_TRACKER_PROTOCOL_ID = 0x41727101980n;
const ACTION_CONNECT = 0;
 
export function buildConnectRequest() {
  const transactionId = randomUInt32();
  const buffer = Buffer.alloc(16);
 
  buffer.writeBigUInt64BE(UDP_TRACKER_PROTOCOL_ID, 0);
  buffer.writeUInt32BE(ACTION_CONNECT, 8);
  buffer.writeUInt32BE(transactionId, 12);
 
  return { buffer, transactionId };
}

Line-by-line reasoning

  • The n suffix makes the protocol ID a BigInt, so writing all eight bytes is exact.
  • Buffer.alloc(16) creates a zero-filled 16-byte packet.
  • writeBigUInt64BE writes eight bytes at offset 0.
  • writeUInt32BE writes action 0 at offset 8 and the transaction ID at offset 12.
  • The function returns both the packet and transaction ID because the parser must later check the reply.

7.3 Connect response layout

OffsetSizeMeaning
04Action. Must be 0 for a successful connect response.
44Transaction ID. Must equal the request ID.
88Connection ID copied into the announce request.

7.4 Parse and validate the response

Connect response parser

JavaScript
export function parseConnectResponse(response, expectedTransactionId) {
  ensureTrackerResponse(response, 16, ACTION_CONNECT, expectedTransactionId);

  return {
    action: response.readUInt32BE(0),
    transactionId: response.readUInt32BE(4),
    connectionId: response.subarray(8, 16),
  };
}

subarray(8, 16) returns the eight connection-ID bytes. We keep them as bytes because the next request only needs to copy them; converting them to a JavaScript Number would be unnecessary and potentially unsafe.

7.5 Generic tracker response validation

Do not trust incoming UDP packets

JavaScript
function ensureTrackerResponse(
  response,
  minimumLength,
  expectedAction,
  expectedTransactionId,
) {
  if (response.length < 8) {
    throw new Error('Tracker response is too short.');
  }

  const action = response.readUInt32BE(0);
  const transactionId = response.readUInt32BE(4);

  if (transactionId !== expectedTransactionId) {
    throw new Error('Tracker response has the wrong transaction ID.');
  }

  if (action === 3) {
    const message = response.subarray(8).toString('utf8');
    throw new Error(`Tracker error: ${message}`);
  }

  if (action !== expectedAction) {
    throw new Error(`Unexpected tracker action: ${action}`);
  }

  if (response.length < minimumLength) {
    throw new Error('Tracker response is shorter than the protocol requires.');
  }
}
