12. Pieces, blocks, queues, and failed requests

12.1 Pieces are not normally requested whole

A torrent piece may be hundreds of kilobytes or several megabytes. Peer request messages normally ask for smaller blocks. This guide uses 16 KiB, or 16 * 1024 = 16,384 bytes, which matches the original tutorial and common protocol practice.

12.2 Piece and block maths

Count expected piece hashes

JavaScript
export const BLOCK_LENGTH = 16 * 1024;

export function numberOfPieces(torrent) {
  const count = torrent.info.pieces.length / 20;
  if (!Number.isInteger(count)) {
    throw new Error('The torrent pieces field is not a multiple of 20 bytes.');
  }
  return count;
}

The final piece may be shorter

JavaScript
export function pieceLength(torrent, pieceIndex) {
  const pieceCount = numberOfPieces(torrent);
  const normalLength = BigInt(torrent.info['piece length']);

  if (pieceIndex < pieceCount - 1) return Number(normalLength);

  const bytesBeforeLastPiece = normalLength * BigInt(pieceCount - 1);
  return Number(totalSizeBigInt(torrent) - bytesBeforeLastPiece);
}

The final block may also be shorter

JavaScript
export function blocksPerPiece(torrent, pieceIndex) {
  return Math.ceil(pieceLength(torrent, pieceIndex) / BLOCK_LENGTH);
}

export function blockLength(torrent, pieceIndex, blockIndex) {
  const begin = blockIndex * BLOCK_LENGTH;
  const remaining = pieceLength(torrent, pieceIndex) - begin;
  return Math.min(BLOCK_LENGTH, remaining);
}

12.4 Per-peer Queue

Each peer gets its own queue containing only pieces that peer says it has. Faster peers naturally finish a request and take another job sooner. A Set prevents repeated have messages from adding the same piece twice to one queue.

src/Queue.js

JavaScript
export class Queue {
  constructor(torrent) {
    this.torrent = torrent;
    this.items = [];
    this.queuedPieces = new Set();
    this.choked = true;
  }

  enqueuePiece(pieceIndex) {
    if (this.queuedPieces.has(pieceIndex)) return;
    this.queuedPieces.add(pieceIndex);

    const count = blocksPerPiece(this.torrent, pieceIndex);
    for (let blockIndex = 0; blockIndex < count; blockIndex += 1) {
      this.items.push({
        index: pieceIndex,
        begin: blockIndex * BLOCK_LENGTH,
        length: blockLength(this.torrent, pieceIndex, blockIndex),
      });
    }
  }

  dequeue() { return this.items.shift(); }
  get length() { return this.items.length; }
}

12.5 Shared Pieces state

All connections share one Pieces object. It tracks every expected block twice: requested means some peer currently owns the job; received means the block has arrived and been written.

Core of src/Pieces.js

JavaScript
export class Pieces {
  constructor(torrent) {
    const makeTable = () =>
      Array.from({ length: numberOfPieces(torrent) }, (_, pieceIndex) =>
        new Array(blocksPerPiece(torrent, pieceIndex)).fill(false),
      );

    this.requested = makeTable();
    this.received = makeTable();
  }

  markRequested(pieceBlock) {
    this.requested[pieceBlock.index][this.blockIndex(pieceBlock)] = true;
  }

  markReceived(pieceBlock) {
    const blockIndex = this.blockIndex(pieceBlock);
    this.requested[pieceBlock.index][blockIndex] = true;
    this.received[pieceBlock.index][blockIndex] = true;
  }

  markFailed(pieceBlock) {
    const blockIndex = this.blockIndex(pieceBlock);
    if (!this.received[pieceBlock.index][blockIndex]) {
      this.requested[pieceBlock.index][blockIndex] = false;
    }
  }

  needed(pieceBlock) {
    return !this.requested[pieceBlock.index][this.blockIndex(pieceBlock)];
  }

  isDone() {
    return this.received.every((blocks) => blocks.every(Boolean));
  }

  blockIndex(pieceBlock) {
    return pieceBlock.begin / BLOCK_LENGTH;
  }
}

12.6 Failed requests

If a socket closes while it owns an outstanding block, markFailed changes requested back to false unless the block was already received. Another peer can then take that job. Without this recovery, one dropped connection could leave the download permanently incomplete.

12.7 Choke and unchoke

Each peer starts in the choked state. A choked peer is not currently allowing us to request blocks. The modern code does not close the connection merely because a choke message arrives; it waits. When an unchoke arrives, the queue may resume.

12.8 have and bitfield

A have payload is one piece index. A bitfield packs availability into bits. For each byte, bit 7 represents the first piece in that byte, then bit 6, down to bit 0. That is why the mask is 1 << (7 - bitIndex).

Translate availability bits into queue jobs

JavaScript
function addBitfieldToQueue(bitfield, torrent, queue) {
  const pieceCount = numberOfPieces(torrent);

  bitfield.forEach((byte, byteIndex) => {
    for (let bitIndex = 0; bitIndex < 8; bitIndex += 1) {
      const pieceIndex = byteIndex * 8 + bitIndex;
      if (pieceIndex >= pieceCount) return;

      const mask = 1 << (7 - bitIndex);
      if ((byte & mask) !== 0) queue.enqueuePiece(pieceIndex);
    }
  });
}
