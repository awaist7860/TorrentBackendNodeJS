5. Open and inspect a torrent

First version of torrent-parser.js

5.1 Create src/torrent-parser.js

First version of torrent-parser.js

JavaScript
import { Buffer } from 'node:buffer';
import crypto from 'node:crypto';
import fs from 'node:fs';
 
import bencode from 'bencode';
 
export function openTorrent(filePath) {
  const file = fs.readFileSync(filePath);
  return bencode.decode(file);
}

Every line explained

Line or expressionWhat it does
import { Buffer } from 'node:buffer'Explicitly imports Node's byte container. Buffer is global in Node, but an explicit import makes the dependency clear.
import crypto from 'node:crypto'Loads hashing and random-byte functions.
import fs from 'node:fs'Loads file-system functions.
import bencode from 'bencode'Loads the installed metainfo encoder/decoder.
export function openTorrent(filePath)Declares a reusable function and exports it to other modules.
fs.readFileSync(filePath)Reads the complete .torrent file into a Buffer. Metainfo files are normally small, so a synchronous read keeps the example simple.
bencode.decode(file)Converts bencoded bytes into JavaScript objects, arrays, numbers, and Buffers.
returnGives the decoded torrent object back to the caller.

Do not call JSON.stringify and assume the result represents all binary data meaningfully. Buffers such as info.pieces are raw hashes. Convert only known text fields with toString(utf8).

5.3 Text helper functions

Safe text conversion and scope check

JavaScript
export function torrentName(torrent) {
  return Buffer.from(torrent.info.name).toString('utf8');
}

export function isSingleFileTorrent(torrent) {
  return torrent.info.files === undefined;
}

Buffer.from makes sure the value is treated as a Buffer before decoding it. isSingleFileTorrent returns true when the files array is absent. The final program stops with a clear message for multi-file torrents instead of writing the logical stream into one incorrect file.

5.4 Read all tracker URLs

Gather primary and alternative trackers

JavaScript
export function trackerUrls(torrent) {
  const urls = [];

  if (torrent.announce) {
    urls.push(Buffer.from(torrent.announce).toString('utf8'));
  }

  if (Array.isArray(torrent['announce-list'])) {
    for (const tier of torrent['announce-list']) {
      const entries = Array.isArray(tier) ? tier : [tier];
      for (const entry of entries) {
        urls.push(Buffer.from(entry).toString('utf8'));
      }
    }
  }

  return [...new Set(urls)];
}

announce-list is normally a list of tiers, and each tier is a list of URLs. The code tolerates a less regular shape by wrapping non-array tiers. Set removes duplicates.

5.5 Choose a UDP tracker

Select the protocol supported by this guide

JavaScript
export function chooseUdpTracker(torrent) {
  const url = trackerUrls(torrent).find((candidate) =>
    candidate.startsWith('udp://'),
  );

  if (!url) {
    throw new Error(
      'No UDP tracker was found in this torrent. ' +
      'This learning client does not yet support HTTP trackers or DHT.',
    );
  }

  return url;
}
