2. Modern Node.js setup and project structure

2.1 Recommended versions

This edition targets Node.js 24 LTS. Node.js 26 is the Current release line at the time of verification, but an LTS release is the safer choice for a learning project because it receives long-term maintenance. The code uses only standard Node APIs plus bencode 4.0.1.

i
Version rule

Use Node.js 24.x LTS for the steps in this guide. A newer Node release will probably work, but the tested target and package engines field are Node 24 or later.

2.2 Check your tools

Run in Terminal, PowerShell, or Command Prompt

Terminal
node --version
npm --version

The first command should print a version beginning with v24 when you use the recommended LTS line. npm is included with Node.js. You also need a text editor such as Visual Studio Code.

2.3 Create the project

Create the folders

Terminal
mkdir modern-torrent-client
cd modern-torrent-client
mkdir src test

The src folder holds application modules. The test folder holds automated checks. The project root holds package.json and index.js.

2.4 package.json

package.json

JSON
{
  "name": "modern-bittorrent-client-tutorial",
  "version": "1.0.0",
  "private": true,
  "description": "A small BitTorrent v1 client built for learning purposes.",
  "type": "module",
  "scripts": {
    "start": "node index.js",
    "test": "node --test"
  },
  "engines": {
    "node": ">=24"
  },
  "dependencies": {
    "bencode": "4.0.1"
  }
}

Line-by-line explanation

PropertyMeaning
nameThe package name used by npm. It does not have to match the folder exactly.
versionYour project version. 1.0.0 is a normal starting value.
privatePrevents accidental publishing to the public npm registry.
descriptionA human-readable summary.
type: moduleMakes .js files use ECMAScript module syntax, so import and export work as written.
scripts.startLets you run npm start -- <arguments>, although direct node index.js is clearer while learning.
scripts.testRuns Node's built-in test runner.
engines.nodeDocuments that this guide targets Node 24 or later.
dependencies.bencodePins the bencode package to 4.0.1 for repeatable installation.

2.5 Install the dependency

Install exactly what package.json specifies

Terminal
npm install

npm creates node_modules and package-lock.json. The lock file records the exact dependency tree installed on your computer. Keep package-lock.json in source control if you put the project on GitHub.

2.7 ES modules in plain English

Modern import/export example

JavaScript
import fs from 'node:fs';
import bencode from 'bencode';

export function openTorrent(filePath) {
  // ...
}

import brings a value from another module into the current file. The node: prefix makes it obvious that fs is a built-in Node module. export makes a function available to other files. A relative import must include the .js extension in this project, for example ./src/download.js.
