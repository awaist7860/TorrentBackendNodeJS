Appendix C. Glossary

Appendix C. Glossary

TermMeaning
AnnounceA tracker request that reports client state and asks for peers.
BEPBitTorrent Enhancement Proposal, a protocol specification or extension document.
BencodeThe byte-oriented data format used by .torrent metainfo and some BitTorrent messages.
Big-endianA byte order that stores the most significant byte first.
BigIntJavaScript integer type for values beyond the exact range of Number.
BitfieldA compact set of availability flags, one bit per piece.
BlockA requested byte range within a piece.
BufferNode.js fixed-length sequence of bytes.
ChokePeer state that prevents us from making new block requests to that peer.
Compact peerSix-byte IPv4 peer entry: four address bytes and a two-byte port.
Connection IDTemporary 8-byte value returned by a UDP tracker connect exchange.
DHTDistributed hash table used to discover peers without a central tracker.
ES moduleStandard JavaScript module format using import and export.
File descriptorSmall operating-system handle used to refer to an open file.
HandshakeFirst peer-wire message that names the protocol, info hash, and peer ID.
HashFixed-length digest used to identify or verify data.
HavePeer message declaring possession of one piece index.
Info dictionaryTorrent metadata section whose bencoded bytes define the v1 info hash.
Info hash20-byte SHA-1 identifier for a BitTorrent v1 torrent.
Keep-aliveFour-byte zero-length peer message used to keep an idle connection open.
LeecherPeer that does not yet have all data.
MetainfoThe structured content stored in a .torrent file.
NATNetwork address translation, commonly used by home routers.
OffsetZero-based position in a Buffer, message, piece, or file.
PeerAnother client in the same torrent swarm.
Peer ID20-byte identifier for a running client.
PieceLarge indexed section of torrent data with an expected hash.
SeederPeer that has all torrent data.
SHA-120-byte hash function used by BitTorrent v1 info hashes and piece hashes.
SwarmAll peers participating in one torrent.
TCPReliable ordered byte-stream transport used for peer connections in this guide.
TrackerService that coordinates peer discovery.
Transaction IDRandom request value echoed by a UDP tracker response.
UDPDatagram transport used by the tracker protocol in this guide.
UnchokePeer state allowing requests.
